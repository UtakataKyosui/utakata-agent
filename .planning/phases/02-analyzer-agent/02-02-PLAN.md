  <name>Task 2: Complexity score formula and _apply_output</name>
  <files>issue_resolver/analyzer.py</files>
  <behavior>
    - _compute_complexity_score(affected_files: list[str], confidence: float, is_ambiguous: bool) -> float: if is_ambiguous → return 11.0. n = len(affected_files). if n > 15 → return round(9.0 + min((n - 15) * 0.1, 2.0), 1). file_score = min(n * 0.4, 6.0). confidence_penalty = (1.0 - confidence) * 3.0. return round(file_score + confidence_penalty, 1). Max for non-ambiguous = 6.0 + 3.0 = 9.0 < 11.0 sentinel.
    - ISSUE_TYPE_VALUES = {"bug", "feature", "refactor"} (module-level constant)
    - ANALYZER_OUTPUT_SCHEMA dict (module-level constant): {"type": "json_schema", "schema": {"type": "object", "properties": {"issue_type": {"type": "string", "enum": ["bug", "feature", "refactor"]}, "affected_files": {"type": "array", "items": {"type": "string"}}, "implementation_plan": {"type": "string"}, "complexity_score": {"type": "number"}}, "required": ["issue_type", "affected_files", "implementation_plan", "complexity_score"], "additionalProperties": False}}
    - _apply_output(ctx: IssueContext, output: dict) -> None: issue_type = output.get("issue_type", ""). If not in ISSUE_TYPE_VALUES → default to "feature". ctx.issue_type = issue_type. ctx.affected_files = output.get("affected_files", [])[:15]. ctx.implementation_plan = output.get("implementation_plan", ""). ctx.complexity_score = float(output.get("complexity_score", 11.0)).
  </behavior>
